Завдання 1. Створення застосунку

Розробити невеликий React-застосунок на вибір:

· менеджер особистих фінансів;

· каталог книг;

· список покупок;

· менеджер подій;

· каталог фільмів.

Застосунок повинен мати щонайменше три функціональні можливості (наприклад, додавання, редагування, видалення або фільтрацію записів).

Завдання 2. Підготовка Docker-образу

1. Створити Dockerfile для свого проєкту.

2. Визначити базовий образ.

3. Налаштувати робочу директорію.

4. Передбачити копіювання файлів проєкту.

5. Налаштувати встановлення залежностей.

6. Визначити команду запуску застосунку.

Завдання 3. Робота з контейнером

1. Створити власний Docker-образ із тегом 1.0.

2. Запустити контейнер на основі цього образу.

3. Призначити контейнеру зрозуміле ім'я.

4. Налаштувати доступ до застосунку через браузер.

5. Переглянути логи контейнера.

6. Перевірити стан контейнера.

7. Зупинити та повторно запустити контейнер.

Завдання 4. Керування версіями образів

1. Створити для власного образу тег 2.0.

2. Переконатися, що обидва теги доступні локально.

3. Порівняти інформацію про образи.

4. Пояснити, для чого може використовуватися версіонування Docker-образів.

Завдання 5. Аналіз роботи Docker

Підготувати короткий звіт, у якому пояснити:

1. Чим образ відрізняється від контейнера?

2. Що відбувається після виконання docker stop?

3. Чим docker rm відрізняється від docker rmi?

4. Для чого потрібна команда docker exec?

5. Чому після видалення контейнера Docker-образ може залишитися на комп'ютері?

6. Які переваги дає запуск React-застосунку в контейнері?
