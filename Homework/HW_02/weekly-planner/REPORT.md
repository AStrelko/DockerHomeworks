# Короткий звіт до домашньої роботи

**Тема:** створення React-застосунку «Мій тижневик» і запуск у Docker.

Застосунок дозволяє додавати події на конкретні дату й час, додавати щорічні події, позначати їх виконаними та видаляти. Календар позначає дні рожевим (щорічні події), синім (заплановані), світло-фіолетовим (обидва види). Події зберігаються в localStorage браузера.

## Відповіді

1. **Образ і контейнер:** образ — шаблон із застосунком та залежностями; контейнер — екземпляр образу із запущеним процесом. Один образ може створити багато контейнерів.
2. **Після `docker stop`:** процес контейнера завершується, але сам контейнер залишається, його видно через `docker ps -a` і можна запустити знову.
3. **`docker rm` і `docker rmi`:** перша команда видаляє контейнер; друга видаляє тег або образ. Для видалення образу спочатку можуть знадобитися видалення контейнерів, які його використовують.
4. **`docker exec`:** запускає команду в працюючому контейнері, наприклад відкриває оболонку `sh` для дослідження його файлів.
5. **Образ після видалення контейнера:** контейнер і образ — різні об'єкти. Видалення екземпляра не видаляє шаблон, потрібний для повторного запуску.
6. **Переваги контейнера для React:** однакове оточення для запуску, незалежність від локальної версії Node.js і чітко описані залежності та порт.

**Теги:** `docker tag weekly-planner:1.0 weekly-planner:2.0` створює друге ім'я для того самого образу, а не змінює код. Після змін код потрібно зібрати з тегом `2.0` окремо.

**Докази практичної частини:** додати скриншоти успішного `docker build`, `docker ps`, сторінки в браузері та `docker logs`. Посилання на GitHub-репозиторій додати після завантаження проєкту.
