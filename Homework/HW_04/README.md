# ESCAPE ONLINE

Інтерактивна React-платформа з каталогом онлайн-квестів. Користувач може знайти потрібний квест, додати його в обране, пройти послідовність завдань і створити власний сценарій. Обрані квести, прогрес і власні сценарії зберігаються у браузері.

## Функціональні можливості

- пошук квестів за назвою та фільтрація за складністю;
- додавання і видалення квестів з обраного;
- покрокове проходження та збереження прогресу;
- створення власного квесту через форму з перевіркою даних;
- профіль зі статистикою та списком обраного;
- збереження обраного, прогресу та створених квестів у `localStorage`.

## Сторінки й маршрути

| Маршрут | Призначення |
| --- | --- |
| `/` | Каталог, пошук і фільтрація квестів. |
| `/quest/:id` | Проходження вибраного квесту. |
| `/create` | Форма створення власного квесту. |
| `/profile` | Статистика та обрані квести. |

## Технології

- React 19;
- TypeScript;
- Vite;
- React Router;
- CSS без додаткового UI-фреймворку;
- `localStorage`;
- Docker і Nginx.

## Dockerfile

У проєкті підготовлено два варіанти:

- `Dockerfile.basic` — базовий одноетапний варіант. Він містить Node.js, залежності й вихідний код та запускає Vite development server.
- `Dockerfile` — оптимізований production-варіант із Multi-stage build.

Оптимізований Dockerfile складається з двох етапів:

1. На етапі `build` точний образ `node:22.12.0-alpine3.20` встановлює залежності через `npm ci` і створює папку `dist`.
2. На етапі `production` точний образ `nginx:1.27.3-alpine3.20` отримує лише готові статичні файли. Node.js, `node_modules` і `src` у фінальний образ не потрапляють.

## Додаткові оптимізації

1. **BuildKit cache mount** — `--mount=type=cache,target=/root/.npm` зберігає завантажені npm-пакети між збірками та прискорює повторне виконання `npm ci`.
2. **Фіксовані версії базових образів** — конкретні версії Node, Nginx і Alpine роблять збірку передбачуваною та захищають від несподіваних змін тегу `latest`.
3. **Оптимізований контекст** — `.dockerignore` не передає Docker локальні залежності, результати складання, налаштування IDE, логи та секрети.
4. **Роздільне копіювання** — маніфести копіюються раніше за вихідний код, тому зміна React або CSS не скасовує кеш шару залежностей.

## Збірка образів

```powershell
docker build -f Dockerfile.basic -t escape-online:basic .
docker build -t escape-online:1.0 .
```

Порівняння:

```powershell
docker image ls escape-online
docker history escape-online:basic
docker history escape-online:1.0
```

| Образ | Розмір | Кількість шарів | Вміст |
| --- | ---: | ---: | --- |
| `escape-online:basic` | 260 MB | 7 | Node.js, залежності, вихідний код |
| `escape-online:1.0` | 47,3 MB | 10 | Nginx і готові файли `dist` |

Multi-stage build зменшив образ на 213 MB, або приблизно на 81,8%.

## Запуск

```powershell
docker run -d --name escape-online -p 8080:80 escape-online:1.0
```

Застосунок відкривається за адресою [http://localhost:8080](http://localhost:8080).

## Docker Hub

Репозиторій: `https://hub.docker.com/r/savaaspid/escape-online`

Доступні версії:

- `1.0` — початкова версія;
- `2.0` — додано фільтр лише обраних квестів, скидання прогресу та позначення версії в інтерфейсі.

Завантаження і запуск версії `1.0`:

```powershell
docker pull savaaspid/escape-online:1.0
docker run -d --name escape-online-v1 -p 8080:80 savaaspid/escape-online:1.0
```

Завантаження і запуск версії `2.0`:

```powershell
docker pull savaaspid/escape-online:2.0
docker run -d --name escape-online-v2 -p 8081:80 savaaspid/escape-online:2.0
```

Версії `1.0` і `2.0` можна запускати паралельно на різних портах для порівняння.
