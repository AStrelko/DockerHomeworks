Завдання 1. Розробка застосунку

Продовження роботи над застосунком, який розробляли на занятті.

Завдання 2. Створення Dockerfile

Підготувати Dockerfile для свого застосунку.

Обов'язково використати:

· FROM;

· WORKDIR;

· COPY;

· RUN;

· ENV;

· CMD;

· EXPOSE.

Додатково використати щонайменше три інші інструкції з лекції на власний розсуд.

Завдання 3. Налаштування збірки

1. Створити .dockerignore.

2. Визначити базовий образ.

3. Додати метадані через LABEL.

4. Передбачити використання параметрів збірки через ARG.

5. Організувати інструкції Dockerfile так, щоб ефективно використовувався кеш.

Завдання 4. Створення власних образів

1. Створити Docker-образ із тегом 1.0.

2. Внести зміни до застосунку.

3. Створити новий образ із тегом 2.0.

4. Порівняти два образи.

5. Пояснити, для чого в реальних проєктах використовують версіонування образів.
